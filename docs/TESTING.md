# Гайд по проверке проекта

Три уровня проверки: типы, юнит-тесты и сквозные (e2e) сценарии в браузере. Первые два нужны перед каждой публикацией, третий — после крупных правок интерфейса.

## 1. Быстрая проверка (1–2 минуты)

```bash
npm install
npx tsc -b          # типы, строгий режим — ошибок быть не должно
npx vitest run      # юнит-тесты (205 шт.), включая паритет EN/RU словарей
npx vite build      # сборка в dist/
```

Если упал тест паритета словарей — в английском словаре появилась кириллица или в одном языке нет ключа из другого.

## 2. Сквозные сценарии (e2e)

Папка `e2e/` — скрипты на Python + Playwright. Они открывают настоящий браузер, играют партии, решают задачи, листают режимы и печатают шаги. Успех — строка `errors []` в конце (ошибок в консоли нет).

### Подготовка (один раз)

```bash
pip install playwright
playwright install chromium
```

В скриптах указан путь к браузеру `/opt/pw-browsers/chromium`. Замените его на свой или уберите аргумент `executable_path=...` (тогда Playwright возьмёт установленный Chromium).

### Раздача сборки

Скрипты ждут сайт по адресу `http://127.0.0.1:4173/chess-coach-ai/`. Адрес с `/chess-coach-ai/` нужен из-за `base` в настройках Vite.

```bash
mkdir serve && ln -s "$(pwd)/dist" serve/chess-coach-ai
cd serve && python3 -m http.server 4173 --bind 127.0.0.1
```

Оставьте сервер работающим и в другом окне запускайте скрипты:

```bash
cd e2e
python3 e2e1.py     # анализ
python3 e2e3.py     # игра с ботом
python3 e2e14.py    # и т. д.
```

### Что покрывают сценарии

| Скрипты | Что проверяют |
|---|---|
| e2e1–e2e2, e2e4, e2e8 | анализ, ходы, редактор позиции |
| e2e3, e2e5 | игра с ботом, часы, смена цвета |
| e2e6–e2e7, e2e9 | задачи, статистика задач |
| e2e10–e2e12 | дебюты: уроки, изучение, тренировка |
| e2e14 | прочие режимы и сохранения |
| e2e16–e2e21 | вход, облачная синхронизация, статус сервера, язык |
| e2e22–e2e24 | дополнительные сценарии интерфейса |
| contrast.py | контраст текста в светлой и тёмной теме: `python3 contrast.py light dark` |

`legacy/` — старые сценарии под удалённые функции (локальные мультиаккаунты); запускать не нужно.

### Облачные сценарии (e2e16–e2e21)

Нужна отдельная сборка с «подставным» Supabase. Настоящий сервер не используется — запросы перехватываются в `e2e16.py`.

```bash
VITE_SUPABASE_URL=https://test.supabase.co VITE_SUPABASE_ANON_KEY=test \
  npx vite build --outDir dist-cloud
mkdir serve2 && ln -s "$(pwd)/dist-cloud" serve2/chess-coach-ai
cd serve2 && python3 -m http.server 4174 --bind 127.0.0.1
```

Ограничение: так проверяется логика приложения, но не настоящий Supabase. Перед выпуском один раз пройдите вход вручную на реальном проекте.

## 3. Типичные проблемы

- **Скрипт висит на ожидании `top-status`** — не запущен сервер на нужном порту или открыт не тот путь (нужен `/chess-coach-ai/`).
- **«strict mode violation … resolved to N elements»** — в приложении одновременно смонтированы четыре режима (скрытые), нужен селектор с `:visible`.
- **Селектор со знаком `+`** (например, `tc-10+5`) берите в кавычки: `[data-testid="tc-10+5"]`.
- **Скрипт ждёт русский текст** — он написан под русский; в начале добавлен `localStorage.setItem('chess-coach-ai:lang:v1','ru')`. По умолчанию язык английский.
- **Сервер умер между запусками** (в некоторых окружениях) — запускайте сервер и скрипт одной командой.

## 4. Ручной чек-лист перед выпуском

1. Сыграть партию с ботом, сделать разбор, сохранить.
2. Решить задачу и проверить, что на главной отмечено «решена» и серия продлилась.
3. Пройти урок дебюта, открыть тренировку.
4. Переключить язык (Настройки): партия и позиция не сбрасываются.
5. Светлая и тёмная тема на телефоне и на ПК.
6. С облаком: регистрация, выход, вход, второй браузер, баннер «есть новые данные».
