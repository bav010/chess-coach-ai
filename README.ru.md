# Chess Coach AI

**Шахматный тренер, который целиком работает в браузере.** Интерактивная доска, анализ позиций движком Stockfish (WebAssembly) и прогресс тренировок. Ни сервера, ни регистрации, ни установки Python: сайт — это статические файлы, которые можно хостить бесплатно на GitHub Pages.

[English version](README.md)

## Возможности

- Сохранённые партии открываются в анализ (и разбор) одним кликом кнопкой «Анализ» — скачивать PGN не нужно.
- Доска с подсветкой легальных ходов, превращением пешки (выбор фигуры), отменой хода, подсветкой последнего хода и кликабельной нотацией (также клавиши ←/→).
- **Режим «Анализ».** Автоматический анализ Stockfish 19 в браузере после каждого хода и перехода по истории (устаревшие расчёты отменяются, результаты кэшируются): оценка (`+1.5`, `−1.5`, `0.0`, `M3`), лучшие линии в SAN, вертикальная шкала оценки, стрелки лучших ходов (яркость, толщина, количество, нумерация), текстовый разбор последнего хода. Панель анализа, шкала оценки, стрелки и оценка ходов отключаются независимо. Загрузка партий из PGN (вставка или файл).
- **Режим «Игра с ботом».** Сила от ≈400 до 3200 ELO (пресеты и ручной ввод), выбор цвета (белые/чёрные/случайно, доска разворачивается), контроль времени (Bullet/Blitz/Rapid/Classical или своё: время, добавка, задержка), независимые часы и правила падения флага, взятые фигуры и материальный баланс, отмена хода, рестарт, сдача, предложение ничьей, корректное определение мата, пата, троекратного повторения, правила 50 ходов и недостатка материала.
- **Разбор партии.** После партии (или для любого загруженного PGN) Stockfish проходит все позиции и строит отчёт: точность сторон, таблица оценок ходов по сторонам, ключевые моменты, резкие перепады оценки, лучшие и худшие решения, стадии партии и график шансов.
- **Работа над ошибками.** Ваши ошибки разыгрываются заново с позиции перед ходом: найдите ход лучше, возьмите подсказку, повторите, посмотрите лучший вариант. Исходная партия не меняется; прогресс сохраняется локально.
- **Редактор позиции.** В режиме анализа кнопка «Расставить позицию» открывает редактор: ставьте и убирайте любые фигуры, выбирайте очередь хода и рокировки, вставляйте FEN или начинайте с текущей позиции; невозможные позиции (нет короля, пешки на крайних горизонталях, шах стороне не на ходу) отклоняются с пояснением. Дальше — анализ и игра за обе стороны с этой позиции.
- **Тактический тренажёр.** Отдельный режим «Задачи»: тема (вилка, связка, двойное нападение, вскрытое нападение, отвлечение защитника, матовые комбинации, тактическая защита), сложность и тип (мат в 1 / 2 / 3+ хода, выигрыш материала). Каждый ход проверяется сразу, три подсказки по нарастающей (идея → фигура → ход), разбор комбинации после успеха, кнопки «Следующая задача», «Попробовать снова», «Показать решение». Статистика (решено, % успеха, время, по темам) хранится в браузере; по слабым темам предлагаются дополнительные задачи.
- Сохранение тренировочных сессий в `localStorage`, счётчики прогресса, скачивание партий в PGN.
- Данные не покидают устройство: никаких аккаунтов, аналитики и запросов на сторонние серверы (кроме шрифтов Google Fonts).
- Работает на телефоне и на любом статическом хостинге.

## Быстрый старт

Нужен [Node.js](https://nodejs.org/) 20 или новее.

```bash
git clone https://github.com/bav010/chess_trainer_ai.git
cd  chess_trainer_ai
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

**Windows:** можно просто дважды кликнуть `start_chess_coach.bat` — он сам установит пакеты и откроет сайт.

| Команда | Что делает |
| --- | --- |
| `npm run dev` | сервер разработки с горячей перезагрузкой |
| `npm run build` | проверка типов и сборка в папку `dist/` |
| `npm run preview` | запуск собранного сайта локально |
| `npm run typecheck` | только проверка TypeScript |

> Собранный `dist/index.html` нельзя открыть двойным кликом (`file://`): браузеры не запускают WebAssembly-движок с локального файла. Используйте `npm run preview` или любой статический сервер.

## Как это устроено

```
src/
  App.tsx        оболочка: шапка, вкладки «Анализ» / «Игра с ботом»
  views/         AnalysisView (анализ, разбор, тренажёр), PlayView (игра с ботом)
  components/    доска, шкала оценки, часы, панели, отчёт разбора, тренажёр
  lib/           чистая логика: партия, оценки, классификация, часы, бот, PGN, разбор (с тестами)
  hooks/         автоматический анализ позиции, настройки
  engine.ts      обёртка над Stockfish: Web Worker + протокол UCI (два экземпляра)
  storage.ts     сессии, разборы и прогресс тренажёра в localStorage
  main.tsx       точка входа React
  style.css      стили
public/engine/   Stockfish.js 19 (lite, однопоточный): .js, .wasm и лицензия
.github/workflows/pages.yml   сборка и публикация на GitHub Pages
```

- **Шахматная логика** (правила, легальные ходы, PGN) — библиотека [chess.js](https://github.com/jhlywa/chess.js).
- **Движок.** Используется сборка `lite-single`: около 1,9 МБ, без многопоточности, поэтому не требует заголовков `COOP/COEP`, которые GitHub Pages не позволяет задавать. Она слабее полной версии, но заметно сильнее любого человека. `engine.ts` запускает её в Web Worker и общается по UCI.
- **Два движка.** Анализ/разбор и бот работают в разных Web Worker, поэтому не мешают друг другу.
- **Единая модель партии.** Стартовая позиция + список ходов в UCI — единственный источник правды (`src/lib/game.ts`); доска, история, взятые фигуры, статус и анализ вычисляются из неё и не могут разойтись.
- **Настройка анализа.** Живой анализ: глубина 22 / до 6 с (`src/hooks/useAnalysis.ts`); разбор — глубина 12–18 по настройке «Качество разбора».

### Методика и ограничения

- **Оценка** показывается с точки зрения белых; оценки движка (для стороны, чей ход) пересчитываются. Шансы на победу = `50 + 50·(2/(1+e^(−0.00368208·cp)) − 1)` (кривая Lichess); шкала использует ту же кривую.
- **Классификация ходов** (значки как в chess.com — на доске, в нотации и в таблице отчёта): блестящий, сильный, лучший, отличный, хороший, дебютный, неточность, ошибка, упущенный шанс, зевок. Потеря = падение шансов на победу у ходившего относительно лучшей линии. По умолчанию: отличный ≤ 2, хороший < 5, неточность ≥ 5, ошибка ≥ 10, зевок ≥ 15 п. п. (меняется в настройках). *Лучший* — первая линия движка. *Сильный* — единственный хороший ход (второй вариант хуже на 15+ п. п., не простое взятие в ответ). *Блестящий* — лучший ход с жертвой материала (минус 2+ после первых четырёх полуходов варианта) в позиции, которая не была уже выигранной и остаётся не хуже равной. *Упущенный шанс* — потеря 5+ п. п. сразу после ошибки соперника (или при упущенном мате), если позиция не рухнула. *Дебютный* — ход из небольшого встроенного списка дебютных линий (не полная база ECO). Особые оценки — эвристики поверх оценок движка, а не официальные критерии chess.com.
- **Точность** хода = `103.1668·e^(−0.04354·потеря) − 3.1669` (0–100), точность стороны — среднее. Это приближённая методика, а не официальный показатель какого-либо сервиса; зависит от глубины анализа.
- **ELO бота приблизительный.** От 1320 до 3190 силу реально ограничивает опция Stockfish `UCI_Elo`; 3200 — полная сила. Ниже 1320 такой опции нет: бот играет на уровне 1320 и дополнительно выбирает другой из своих пяти лучших ходов с вероятностью, растущей при снижении рейтинга (таблица `LOW_ELO_SLIP` в `src/lib/bot.ts`; подобрана по матчам движка с собой и по отзывам игроков, разница между соседними слабыми уровнями небольшая). Перед ходом бот выдерживает «человеческую» паузу (`humanDelayMs`): она масштабируется под длину партии (минутная — доли секунды на ход, пятиминутная — секунды), чем выше рейтинг, тем она короче, в дебюте и для вынужденных или очевидных ходов почти нулевая, в острых позициях дольше, плюс случайный разброс с редкими долгими раздумьями; на часы она никогда не давит.
- **Текстовые пояснения** сообщают только проверяемые факты (взятие, шах, мат, изменение оценки, лучший вариант); Stockfish сам ходы не объясняет.
- Материальный баланс считается по взятым фигурам (П=1, К=С=3, Л=5, Ф=9) и не зависит от оценки движка.

### База задач

`src/data/puzzles.json` — статичный набор задач, проверенный движком (сервер не нужен). Он сгенерирован заранее Stockfish 19 (`scripts/gen-puzzles.ts`): позиции берутся из самоигры ослабленного движка, а позиция становится задачей, только если глубокий поиск (глубина 20) доказывает **единственное** решение — форсированный мат (`score mate`, без равнозначной альтернативы), тактику, где лучший ход обгоняет вторую линию не менее чем на 20 п.п. шансов на победу, или защиту от реальной угрозы (поиск «с пропуском хода» показывает, что иначе соперник выигрывает). Темы определяются по геометрии позиции проверенной линии (`src/lib/puzzleThemes.ts`); позиции без распознанной темы отбрасываются — непроверенное задачей не выдаётся. `scripts/build-puzzles.ts` пересобирает JSON. Сейчас в базе 292 задачи: 140 на мат (в 1–4 хода), 70 на защиту, по теме — вилок 37, связок 19, вскрытых нападений 17, двойных нападений 15, отвлечений 7 (редких тем меньше: их труднее найти в партиях; базу можно расширить генератором). Во время решения ход, отличающийся от сохранённого, проверяет Stockfish в браузере (другой мат той же длины или равноценный выигрыш), поэтому верные альтернативные решения принимаются; неверный ход успехом не засчитывается никогда.

### Тесты

`npm test` запускает юнит-тесты (правила, взятия, часы, формат оценки, классификация, калибровка и время раздумий бота, PGN, отчёт разбора, проверка задач, подсказки, статистика и база задач).
- **Хранение.** `storage.ts` пишет в `localStorage` ключ `chess-coach-ai:sessions:v1` (до 200 последних сессий). Данные остаются в браузере пользователя.
