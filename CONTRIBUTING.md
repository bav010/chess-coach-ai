## Thank you for your interest in contributing!

1. Fork the repository and create a branch: `git checkout -b feature/your-feature-name`.
2. Install dependencies with `npm install` and start the development server using `npm run dev`.
3. Make your changes. Follow the style of the surrounding code: strict TypeScript, no unnecessary dependencies.
4. Make sure `npm run build` completes without errors (the same check is performed by CI).
5. Open a pull request and describe what you changed and why. For UI changes, include a screenshot.

Please report bugs and submit ideas as Issues. Include the steps to reproduce the issue, the expected behavior, the actual behavior, your browser, and your operating system.

By submitting code, you agree that it will be distributed under the project's license: GPL-3.0-or-later.
