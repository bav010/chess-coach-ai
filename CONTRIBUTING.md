# Участие в разработке

Спасибо, что хотите помочь!

1. Сделайте форк и создайте ветку: `git checkout -b feature/название`.
2. Установите зависимости: `npm install`, запустите `npm run dev`.
3. Внесите изменения. Придерживайтесь стиля соседнего кода: TypeScript в строгом режиме, без лишних зависимостей.
4. Проверьте, что `npm run build` проходит без ошибок (то же самое делает CI).
5. Откройте pull request и опишите, что и зачем изменено. Для изменений интерфейса приложите скриншот.

Багрепорты и идеи оформляйте как Issues: что делали, что ожидали, что получили, браузер и ОС.

Отправляя код, вы соглашаетесь, что он распространяется под лицензией проекта — GPL-3.0-or-later.
